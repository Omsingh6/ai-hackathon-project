# CampusConnect AI Dashboard

CampusConnect AI Dashboard is a no-backend web application for managing campus ambassador programs. It helps organizations assign tasks, auto-score activity, rank ambassadors, and motivate students with gamification.

## Problem It Solves

Campus ambassador programs often run across spreadsheets, forms, and WhatsApp groups. That makes it hard for managers to track activity, recognize top performers, and keep ambassadors motivated.

CampusConnect creates one centralized dashboard for:

- Task completion tracking
- Points and auto-scoring
- Proof upload review
- Real-time leaderboard ranking
- Levels, badges, streaks, and rewards
- AI-style performance suggestions

## Features

- Ambassador task completion form
- Task types: social post, referral, content creation
- Points engine with live score updates
- Top 5 leaderboard sorted by score
- Levels: Beginner, Active, Champion
- Badges and reward labels
- Streak tracking
- Proof upload filename tracking for manager review
- Dashboard stats for total users, total tasks, top performer, and average score
- AI analyzer for tasks, referrals, and content impact
- Dark mode toggle
- Reset system button
- LocalStorage persistence
- Responsive modern UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Browser LocalStorage

No backend, database, or framework is required.

## How to Run

Open `index.html` in any modern browser.

## Demo Flow

1. Open the dashboard and show the seeded leaderboard.
2. Enter a new ambassador name.
3. Select a task and optionally attach proof.
4. Click `Complete Task`.
5. Show the updated stats, activity feed, leaderboard, streak, and reward.
6. Run the AI Analyzer.
7. Toggle Dark Mode.
